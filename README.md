# 🌸 K-Drama AI Recommender  
🎥 Discover your next favorite Korean drama using AI!  
Built with Python, Machine Learning, and PyQt5.

[⭐ Star this repo](https://github.com/sanvega9/K-Drama-AI-Recommender-) if you love K-Dramas + AI!

---

## 🎯 Overview

This AI-powered K-Drama recommender uses **Natural Language Processing (NLP)** and **machine learning** to suggest Korean dramas based on user input (title or actor). The app features a dynamic **PyQt5 GUI** with a beautiful animated background for an engaging experience.

Whether you're into thrillers like *Vincenzo*, romances like *Crash Landing on You*, or fantasy like *Goblin*, this app helps you find your next binge-worthy show!

---

## 🧠 Key Features

- 🔍 Search by **K-Drama title** or **actor name**
- 🤖 AI recommendations using **TF-IDF + Cosine Similarity**
- 💻 Beautiful **PyQt5 GUI** with animated background (GIF)
- 📚 Built-in dataset of K-Dramas and metadata
- ⚡ Instant results, no internet connection required
